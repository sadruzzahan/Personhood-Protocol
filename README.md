# Personhood Protocol

`protocol-site` artifact plus `api-server` and `mockup-sandbox` for a personhood / governance-adjacent narrative experience.

## 💼 Real-World Use Case
Researchers and communities prototyping identity, attestation, or governance storytelling on the web—**not** a turnkey enterprise SKU as-is.

## 💰 Potential Value
- Long-horizon value tied to standards, grants, or ecosystem partnerships rather than immediate SaaS MRR.
- Useful hiring signal for protocol-minded product engineering and typed API discipline.

## 🚀 Demo / Access
Self-hosted / local only. Run the workspace with pnpm; no public URL declared in-repo.
